Cómo se publicó esta página en GitHub Pages

Manual paso a paso · resultado: yefrinp.github.io

Ver la línea de tiempo de filosofía →

Requisitos

  • Una cuenta de GitHub. Aquí se usó yefrinp
  • El archivo HTML de la página (index.html).

Regla clave: la dirección USUARIO.github.io solo funciona si el repositorio se llama exactamente así, con el mismo nombre de la cuenta.

Publicación

1Preparar el archivo

  1. Crea una carpeta para el sitio. Aquí fue Downloads\yefrinp.github.io.
  2. Copia ahí index.html y cámbiale el nombre a index.html.

GitHub Pages abre index.html como página principal; con otro nombre el sitio da error 404.

2Crear el repositorio local

Abre una terminal dentro de la carpeta y ejecuta estos comandos, uno por uno:

git init -b main
git add index.html
git commit -m "Landing: línea de tiempo de filosofía"

3Crear el repositorio en GitHub

  1. Entra a github.com/new.
  2. En Owner elige tu cuenta (yefrinp).
  3. En Repository name escribe exactamente yefrinp.github.io. Debe salir en verde el mensaje “is available”.
  4. En Visibility elige Public.
  5. No agregues README, .gitignore ni licencia. El repositorio tiene que quedar vacío.
  6. Haz clic en Create repository.

4Subir el archivo

Desde la misma terminal:

git remote add origin https://github.com/yefrinp/yefrinp.github.io.git
git push -u origin main

Si Git nunca ha iniciado sesión en esa PC, se abre el navegador para que entres a GitHub. Aquí la sesión ya estaba guardada y el push fue directo.

5Activar GitHub Pages

  1. En el repositorio ve a Settings, luego a Pages.
  2. En Source deja Deploy from a branch.
  3. En Branch cambia None por main y la carpeta por / (root).
  4. Haz clic en Save. Debe aparecer el mensaje “GitHub Pages source saved.”

Aquí GitHub no lo activó solo. La rama estaba en “None” y hubo que elegir main a mano.

6Esperar la publicación

  1. Ve a la pestaña Actions del repositorio.
  2. Espera a que el proceso “pages build and deployment” termine con check verde. Tarda cerca de un minuto.
  3. Abre yefrinp.github.io.

Si todavía sale 404 después del check verde, recarga con Ctrl + F5, porque puede ser la caché del navegador.

Más opciones

Alternativa sin terminal

En lugar de los pasos 2 y 4:

  1. Crea el repositorio como en el paso 3.
  2. En la página del repositorio vacío haz clic en “uploading an existing file”.
  3. Arrastra el index.html y haz clic en Commit changes.
  4. Sigue con los pasos 5 y 6.

Estructura actual del sitio

  • index.html: este manual.
  • linea-de-tiempo.html: la línea de tiempo de filosofía (antes era el index.html).

Cómo actualizar la página después

Edita el archivo en la carpeta local y luego ejecuta:

git commit -am "Actualizar landing"
git push

La página se actualiza sola en uno o dos minutos.

Notas

  • Cada cuenta solo puede tener un sitio USUARIO.github.io. Para otras páginas crea un repositorio con otro nombre (por ejemplo filosofia) y activa Pages igual. Esa quedaría en yefrinp.github.io/filosofia.
  • Todo lo que está en el repositorio es público, incluido el nombre y el número de cuenta que muestra la línea de tiempo.

Consejo: haz clic en un comando para seleccionarlo completo y copiarlo.
